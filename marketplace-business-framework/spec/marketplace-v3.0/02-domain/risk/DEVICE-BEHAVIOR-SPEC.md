# Device / Behavior Risk SPEC

Signals can include:
deviceFingerprintRef
IP reputation
session age
login velocity
account/device fanout
payment instrument relationship
delivery address relationship
merchant-buyer graph
coupon/flash participation velocity
refund/aftersale history

Raw passwords, authentication secrets and payment credentials are never included.

Feature snapshots must be explainable enough for audit while respecting retention/privacy policy.
