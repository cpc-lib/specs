# IP / Counterfeit Governance SPEC

Aggregates:
- IpComplaintCase
- AuthenticityReview

Flow:
complaint
-> evidence collection
-> seller response
-> optional temporary product hold
-> platform review
-> decision
-> violation/penalty
-> appeal.

Evidence may include:
brand authorization,
purchase source,
serial/lot information,
inspection report,
rights-holder evidence,
product/order snapshots.

Repeat-offender policy can escalate merchant risk/penalties.
