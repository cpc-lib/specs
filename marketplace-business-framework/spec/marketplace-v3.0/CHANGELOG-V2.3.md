# CHANGELOG V2.3

## Added
- first-class FulfillmentOrder/Package/Shipment model
- warehouse routing snapshot
- partial shipment and package item quantity model
- delivery confirmation / rejection facts
- digital/virtual fulfillment
- ReturnOrder / ReverseShipment / ReturnInspection
- ExchangeOrder
- RepairOrder
- return stock disposition
- explicit aftersale timeout clocks
- dispute evidence records
- fulfillment & reverse-logistics OpenAPI
- expanded states/events/tests/Saga contracts

## Compatibility
V2.3 is additive over V2.2. Payment, funding responsibility, clearing,
refund quota, settlement and accounting semantics remain unchanged.
