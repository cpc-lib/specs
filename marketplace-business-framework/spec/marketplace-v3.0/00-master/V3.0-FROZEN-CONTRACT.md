# V3.0 FROZEN CONTRACT

## Status
FROZEN FOR CODEGEN

## What is frozen
- domain boundaries
- source-of-truth ownership
- aggregate state-machine semantics
- money/inventory invariants
- API namespaces and behavioral command style
- event envelope/versioning
- Flyway per-service migrations
- sharding routing keys for hot families
- idempotency requirements
- settlement/refund/payout UNKNOWN semantics
- search/read-model eventual consistency
- merchant/risk/governance boundaries

## What remains capacity/config driven
- physical DB shard count
- table shard count
- Redis cluster size
- Kafka/RabbitMQ partitions/queues
- ES shard/replica count
- JVM resources
- autoscaling thresholds
- provider implementation/vendor
- legal/compliance policy per deployment jurisdiction

## Forbidden during codegen
- cross-service repository access
- generic `updateStatus`
- double-based money
- Redis-only source of inventory truth
- client-authoritative price
- client-authoritative merchant scope
- direct ES dual-write in business transaction
- deletion of finance/payment/refund/settlement facts
- provider timeout treated as definitive FAILED
- direct support/governance/risk mutation of foreign service DB
