# 一人 + AI Roadmap — SPEC 7.9 Baseline

## 总体基线

- 1 名全栈偏 Java 后端工程师 + AI Coding Assistant
- 每周有效容量：5 人日
- Production V1：**46 周开发 + 4 周联调 Buffer = 50 周 / 250 人日**

AI 不视为第二名全职开发者。
