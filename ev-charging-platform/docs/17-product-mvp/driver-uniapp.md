# Driver UniApp Product MVP

## Primary journey

```text
Open App
→ Discover station
→ Station detail
→ Select connector / scan code
→ Login if required
→ Start charging
→ Poll session progress
→ Stop charging
→ Order list
→ Create payment
```

Station discovery/detail is public.

Charging, orders and payment require MEMBER authentication.
